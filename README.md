**Openspace organizer**

The Python program randomly assigns people from an existing list of colleagues to 6 tables with 4 seats each in an opensapce, using Object Oriented Programming.

At each run you can display a different disposition of people at the tables.

The list of colleagues is imported from a txt file containing people, so the handled list can be easilly updated by adding names in the file.

I nice thing to add to this script would be to add code for properly handle a higher number of people than the number of seat available in the openspace.
